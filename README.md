# Tasker (My Tasker Dev)

A fast, minimal, developer-focused desktop checklist and scheduling app built with Electron, Svelte, TypeScript, and Tailwind CSS.

## Features

- 📅 **Schedule & Daily Tasks**: Plan and track tasks by date with rollover support.
- ⏱️ **Timer & Notifications**: Built-in timers and schedule notification watchers.
- 🤖 **AI Assistant**: Intelligent chat assistant integration for task breakdowns and scheduling.
- 🎨 **Modern Interface**: Resizable sidebar, dark/light theme support, and markdown rendering.
- 💻 **Cross-Platform Desktop App**: Built using Electron, Vite, and Svelte.

## Tech Stack

- **Framework**: Svelte + Vite
- **Desktop Runtime**: Electron
- **Styling**: Tailwind CSS + PostCSS
- **Language**: TypeScript
- **Bundler**: esbuild & Vite
- **Storage**: electron-store

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Build & Package

```bash
# Build production bundle
npm run build

# Package desktop application
npm run package
```
